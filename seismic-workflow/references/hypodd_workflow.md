# HypoDD 完整操作流程

## 概述

HypoDD 双差定位分两步：
1. **ph2dt**：波形互相关 + 目录重合拾取，生成事件对差分走时 `dt.ct`
2. **hypoDD**：用差分走时反演事件相对位置

包装器 `scripts/run_hypodd.py` 已封装全流程；本文供调参时参考。

## 前置条件

- 绝对定位目录（Phase 5 输出）作为初始位置
- 预处理后的波形（去响应、带通滤波后）
- 事件数 ≥ 50（太少时事件对不足，收敛困难）

## 关键参数（hypoDD.inp 模板）

```
DTCT  0 -10 10 1     # dt.ct 权重选择
IDRC  3              # 迭代方式
MAXDIST 200          # 事件-台站最大距离 km
MINLINK 8            # 事件对最少连接数（核心参数）
MAXSEP 10            # 事件对最大间距 km
CLUSTER 5
OBSCC  8             # 互相关数据权重
OBSCT  4             # 目录数据权重
ITER   4             # LSQR 迭代次数
```

### 调参建议

| 症状 | 调整 |
|------|------|
| 重定位事件数远少于输入 | 降低 MINLINK 至 6，或增大 MAXSEP |
| RMS 不降反升 | 减小 OBSCC 权重；检查速度模型 |
| 收敛失败 | 减少 ITER；检查是否有离群事件 |

## 纯 Python 回退说明

`scripts/simple_dd.py` 是简化版 DD：仅做差分时间的台站校正项反演，
**不求解完整的震源参数+速度联合反演**。适用场景：

- 数百事件的小数据集原型验证
- 教学演示双差法原理

精度预期：介于绝对定位与完整 HypoDD 之间，无法达到 0.1 s/百米级。

## 结果验证

1. 对比重定位前后深度分布：双差结果应更集中、呈层状分布。
2. 相对位置变化应 < 2–3 km；个别大幅漂移的事件需人工检查。
3. 用 `qc_and_plot.py` 的残差图确认 RMS 改善。
