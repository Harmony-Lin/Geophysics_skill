# 速度模型选择指南

## 为什么速度模型重要

绝对定位误差主要来自走时计算的偏差。一维分层模型与真实地下结构的差异
直接转化为震源位置系统偏差：**水平方向 ~0.5–2 km，深度方向 2–5 km**
（纯 Python Geiger 迭代后端的典型值）。

## 选择流程

1. **优先使用研究区已发表模型**：查区域内地震学研究（层析成像、
   接收函数文献），通常给出 P 波速度-深度表。
2. **无区域模型时用全球模型**：IASP91 或 AK135（`assets/iasp91.tvel`），
   对地壳结构简单的稳定地区可接受。
3. **台站密集、事件浅时谨慎**：浅源地震对浅部速度梯度敏感，
   全球模型的沉积层缺失会系统性抬高深度。

## .tvel 文件格式

```
# 深度(km)  Vp(km/s)  Vs(km/s)  密度(可选)
0.0         5.8       3.36
20.0        6.5       3.75
35.0        8.04      4.47      # Moho 界面用速度跳变表达
```

- 每行一层，深度递增；界面由相邻层速度差表达。
- 最深一层作为半空间。
- S 波缺失时可填 `nan`，脚本按 Vp/1.73 换算。

## 常见区域参考值（中国大陆，粗略）

| 区域 | 地壳厚度 | 上地壳 Vp | 下地壳 Vp |
|------|---------|-----------|-----------|
| 华北平原 | 33–36 km | 5.8–6.1 | 6.6–6.9 |
| 郯庐断裂带 | 33–38 km | 6.0 | 6.7 |
| 青藏高原东缘 | 50–65 km | 5.8–6.2 | 6.6–7.0 |

> 以上仅为量级参考，正式研究必须引用具体文献模型。

## 验证方法

定位后检查：
- 残差 RMS 应 < 0.5 s（好）或 < 1.0 s（可接受）；更大说明模型不合适。
- 深度分布不应堆积在搜索边界或某一层界面上（系统偏差信号）。
